# FFA Interactive Sermons

Interactive sermon pages (slides, notes, audio clips, Theater mode, guided tour).

## Structure
- `sermons/YYYY-MM-DD/` - current, live version of each sermon
  - `index.html` - the interactive page
  - `slides/` - slide images
  - `resources/` - sermon notes, lesson guides, transcripts
- `templates/` - starting templates for new sermons
- `docs/` - project instructions and slide config reference
- `assets/` - shared images
- `archive/` - earlier sermons, previous versions and experiments
